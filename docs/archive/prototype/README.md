# Ранний прототип Olimp

Этот каталог сохраняет исходные `index.html`, `chat_api.py` и `requirements.txt` для истории проекта. Это отдельная версия интерфейса и чата на Python/Flask; текущий Mini App находится в `apps/web`, API — в `apps/api`, бот — в `apps/bot`.

Прототип не входит в pnpm-сборку и Docker-образ. Прежний сценарий копирования исходников в `/var/www/html/` удалён. Запуск и обновление текущего приложения описаны в [инструкции Docker](../../DEPLOYMENT.md).
