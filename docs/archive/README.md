# Архив проекта

Здесь сохранены первоначальный `PROJECT_BRIEF.md`, прежние отчёты из `data/` и [ранний HTML/Python-прототип](prototype/README.md). Они отражают состояние на момент создания, могут содержать старые пути, числа записей и правила обработки дат. Это история работы, а не актуальная инструкция или подтверждение готовности текущей версии.

Актуальный запуск описан в [README](../../README.md). Новые проверки запускаются через `pnpm check` и `pnpm test:integration`. Отчёты импорта и справочников создаются локально в `data/` и не публикуются автоматически.
