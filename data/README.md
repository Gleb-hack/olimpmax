# Данные Olimp

| Папка | Содержимое |
| --- | --- |
| `catalog/` | Исходная выгрузка olimpiada.ru: `olimpiady.csv`, UTF-8, разделитель `;` |
| `reference/` | Дополнительные карточки, уровни, этапы, вузы и льготы; [описание источников](reference/README.md) |
| `faq/` | Ответы на вопросы об олимпиадах с источниками |
| `assistant/` | Список сайтов для поиска ассистента |

Приложение читает каталог из PostgreSQL после `pnpm db:import`. Порядок обновления описан в [инструкции](../docs/CATALOG.md).

`pnpm db:audit`, `pnpm data:check` и `pnpm db:import` создают отчёты в этой папке. Они исключены из Git, поскольку описывают конкретный запуск.
