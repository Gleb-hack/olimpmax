# Olimp — олимпиады и личный план в MAX

Цифровое решение для школьников: помогает найти подходящие олимпиады, сохранить их в личный план и следить за сроками. Состоит из Mini App в MAX, HTTP API и бота с напоминаниями.

---

## Проверка решения

Основной сценарий доступен только через MAX.

Ссылка на бота: https://max.ru/t607_hakaton_max_bot

### Пошаговый сценарий проверки

1. Откройте бота по ссылке в MAX (мобильная или веб-версия).
2. Отправьте команду `/start`.
3. Нажмите кнопку «Открыть приложение».
4. В мини-приложении выберите фильтры (предмет, класс, уровень).
5. Найдите олимпиаду в каталоге и добавьте её в личный план.
6. Вернитесь в чат с ботом и отправьте `/plan`.
7. Отправьте `/settings`, чтобы настроить напоминания.

### Примеры ожидаемого поведения

| Действие | Ожидаемый результат |
|----------|---------------------|
| `/start` | Бот приветствует и показывает кнопку «Открыть приложение» |
| Кнопка «Открыть приложение» | Открывается Mini App с каталогом олимпиад |
| Добавление олимпиады в план | Олимпиада появляется в разделе «План» |
| `/plan` | Бот присылает список сохранённых олимпиад |
| `/settings` | Бот показывает текущие настройки напоминаний |

## Возможности

- Каталог: поиск, фильтры, сравнение олимпиад, расписание и ссылки на источники.
- Личный план: сохранение олимпиад, календарь, заметки и управление отслеживанием.
- Поступление: уровни олимпиад, карточки вузов и справочник льгот; направления подготовки и 2400 программ 38 вузов с экзаменами и проходными баллами.
- Ассистент «Олимп»: ответы по каталогу и справочникам, поиск на сайтах организаторов и вузов со ссылками на источники.
- Бот MAX: напоминания о сроках по местному времени, кнопка «Я зарегистрировался», команды `/plan` и `/settings`.
- Профиль: вход через MAX, учебные предпочтения и сохранение плана на сервере.

Стек: React, TypeScript, Vite, MAX UI, Fastify, Zod, Drizzle, PostgreSQL 16, pnpm workspace, Docker Compose и Caddy.

## Запуск одной командой

```bash
cp .env.example .env   # заполнить POSTGRES_PASSWORD, JWT_SECRET, MAX_BOT_TOKEN
docker compose up -d   # поднимает всё: БД, миграции, API, бота, web
```

### Сервисы

| Сервис | Назначение | Порт |
|--------|-----------|------|
| `postgres` | База данных | 55432 |
| `migrate` | Миграции и импорт данных | — |
| `api` | HTTP API | 3001 |
| `bot` | Бот MAX (long polling) | — |
| `web` | Мини-приложение | 8080 |

Проверка:
- API: http://127.0.0.1:3001/health
- Web: http://127.0.0.1:8080

### Остановка и повторный запуск

```bash
docker compose down      # остановить
docker compose up -d     # запустить снова
```

### Параметры окружения

| Переменная | Назначение |
|-----------|-----------|
| `POSTGRES_PASSWORD` | Пароль PostgreSQL (обязательно) |
| `JWT_SECRET` | Секрет для JWT (обязательно, не менее 32 символов) |
| `MAX_BOT_TOKEN` | Токен бота MAX (обязательно) |
| `DEEPSEEK_API_KEY` | Ключ DeepSeek для ассистента (опционально) |
| `DEEPSEEK_MODEL` | Модель DeepSeek (по умолчанию `deepseek-flash`) |
| `BOT_REMINDER_HOUR` | Час начала напоминаний (по умолчанию 16) |
| `BOT_REMINDER_UNTIL_HOUR` | Час окончания напоминаний (по умолчанию 21) |
| `BOT_CHECK_MINUTES` | Интервал проверки (по умолчанию 15) |

## Внешние сервисы и интеграции

- MAX API — платформа, в которой работает бот и Mini App.
- DeepSeek API — для ассистента (опционально; без ключа чат не работает).

---

## Тестовые данные

- Каталог олимпиад — публичные данные с указанием источников.
- Персональные данные не используются.
- Вход в приложение выполняется через MAX.
- Для локальной разработки используется `ALLOW_DEV_AUTH=true` (только в dev-режиме).

---

## Данные и ограничения

Основной набор — `data/catalog/olimpiady.csv` (640 записей, выгрузка от 24.09.2026, разделитель `;`). Справочники дополняют его этапами, уровнями и льготами. После импорта приложение читает PostgreSQL. Повторный импорт обновляет каталог и сохраняет пользовательские планы.

Расписание и правила приёма могут меняться: у данных сохраняются источники. Часть дат без года рассчитывается по сезону 2026/27 и помечается как оценочная. Перед участием нужно сверять сроки и льготы с организатором или вузом. Ассистент зависит от внешнего API; автоматического обновления всего каталога нет.

---

## Известные ограничения

- Ассистент зависит от внешнего API DeepSeek — без ключа чат не работает.
- Автоматического обновления каталога нет — данные импортируются вручную.
- Часть дат без года рассчитывается по сезону 2026/27 и помечается как оценочная.
- Локальный вход (`ALLOW_DEV_AUTH=true`) работает только в режиме разработки и запрещён в production.
- Расписание и правила приёма могут меняться — перед участием сверяйтесь с организатором.
