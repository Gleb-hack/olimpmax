# Olimp — олимпиады и личный план в MAX

Olimp помогает школьнику найти подходящие олимпиады, сохранить их в личный план и следить за сроками. Проект состоит из Mini App в MAX, API и бота с напоминаниями.

## 🚀 Проверка решения

**Основной пользовательский сценарий доступен только через MAX.**

🔗 **Ссылка на бота:** https://max.ru/t607_hakaton_max_bot

### Пошаговый сценарий проверки

1. Откройте ссылку на бота в MAX (мобильная или веб-версия).
2. Отправьте команду `/start`.
3. Нажмите кнопку **«Открыть приложение»**.
4. В мини-приложении:
   - Выберите фильтры (предмет, класс, уровень олимпиады).
   - Найдите олимпиаду в каталоге.
   - Откройте карточку олимпиады и добавьте её в личный план.
   - Перейдите в раздел «План» — убедитесь, что олимпиада сохранена.
5. Вернитесь в чат с ботом:
   - Отправьте `/plan` — бот покажет сохранённые олимпиады.
   - Отправьте `/settings` — бот покажет настройки напоминаний.

### Примеры ожидаемого поведения

| Действие | Ожидаемый результат |
|---|---|
| `/start` | Бот приветствует и показывает кнопку «Открыть приложение» |
| Кнопка «Открыть приложение» | Открывается Mini App с каталогом олимпиад |
| Добавление олимпиады в план | Олимпиада появляется в разделе «План» |
| `/plan` | Бот присылает список сохранённых олимпиад |
| `/settings` | Бот показывает текущие настройки напоминаний |

## Возможности

- **Каталог:** поиск, фильтры, сравнение олимпиад, расписание и ссылки на источники.
- **Личный план:** сохранение олимпиад, календарь, заметки и управление отслеживанием.
- **Поступление:** уровни олимпиад, карточки вузов и справочник льгот; направления подготовки и 2400 программ 38 вузов с экзаменами и проходными баллами, связь «олимпиада → направление → программа» и цель ученика (направления и вузы) в профиле.
- **Ассистент «Олимп»:** ответы по каталогу и справочникам, поиск на сайтах организаторов и вузов со ссылками на источники. Для чата нужен серверный ключ DeepSeek.
- **Бот MAX:** надстройка к мини-приложению — напоминания о сроках по местному времени, сообщения о перенесённых датах, кнопка «Я зарегистрировался», команды `/plan` и `/settings`; вопросы и поиск бот открывает в приложении с уже введённым текстом.
- **Профиль:** вход через MAX, учебные предпочтения и сохранение плана на сервере.

**Стек:** React, TypeScript, Vite, MAX UI · Fastify, Zod, Drizzle · PostgreSQL 16 · pnpm workspace · Docker Compose и Caddy.
