# Olimp — олимпиады и личный план в MAX

Olimp помогает школьнику найти подходящие олимпиады, сохранить их в личный план и следить за сроками. Проект состоит из Mini App в MAX, API и бота с напоминаниями.

## Возможности

- **Каталог:** поиск, фильтры, сравнение олимпиад, расписание и ссылки на источники.
- **Личный план:** сохранение олимпиад, календарь, заметки и управление отслеживанием.
- **Поступление:** уровни олимпиад, карточки вузов и справочник льгот; направления подготовки и 2400 программ 38 вузов с экзаменами и проходными баллами, связь «олимпиада → направление → программа» и цель ученика (направления и вузы) в профиле.
- **Ассистент «Олимп»:** ответы по каталогу и справочникам, поиск на сайтах организаторов и вузов со ссылками на источники. Для чата нужен серверный ключ DeepSeek.
- **Бот MAX:** напоминания о сроках, команды `/plan` и `/settings`, переход к карточке олимпиады.
- **Профиль:** вход через MAX, учебные предпочтения и сохранение плана на сервере.

**Стек:** React, TypeScript, Vite, MAX UI · Fastify, Zod, Drizzle · PostgreSQL 16 · pnpm workspace · Docker Compose и Caddy.

## Быстрый старт

Нужны **Node.js 22+**, **pnpm 11.25.0**, **Docker с Compose** и Git. Все команды ниже выполняются из корня проекта. Для каталога и личного плана ключи внешних сервисов не нужны.

```bash
git clone https://github.com/Gleb-hack/olimpmax.git
cd olimpmax
pnpm install --frozen-lockfile
cp .env.example .env
cp apps/web/.env.example apps/web/.env
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

В `.env` вставьте сгенерированную строку в `JWT_SECRET` и установите `ALLOW_DEV_AUTH=true` для локального входа. Остальные значения можно оставить из примера. Затем:

```bash
docker compose up -d --wait
pnpm db:migrate
pnpm db:import
pnpm dev
```

Откройте **[http://127.0.0.1:5173](http://127.0.0.1:5173)** и войдите через локальный демонстрационный режим. API работает на порту 3001, PostgreSQL — на 55432. Проверка API: [http://127.0.0.1:3001/health](http://127.0.0.1:3001/health).

Вне MAX локальный вход доступен только в режиме разработки. Production требует запуска внутри MAX и действительного токена бота. Ключ DeepSeek задаётся в корневом `.env` как `DEEPSEEK_API_KEY`; секреты нельзя помещать в переменные `VITE_*`.

Если PostgreSQL 16 установлен локально, вместо Docker можно использовать `pnpm db:local start` (`PG_BIN` задаёт путь к его исполняемым файлам). Не запускайте оба варианта на одном порту. Остановка: `docker compose stop` или `pnpm db:local stop`; `Ctrl+C` останавливает сервер разработки.

## Команды

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | API и интерфейс в режиме разработки |
| `pnpm dev:bot` | Бот MAX; нужен `MAX_BOT_TOKEN` |
| `pnpm db:migrate` | Применить миграции базы |
| `pnpm db:import` | Загрузить каталог и справочники, сохранив личные планы |
| `pnpm check` | Проверить типы, модульные тесты, справочники и сборку |
| `pnpm test:integration` | Проверить API и импорт с PostgreSQL |
| `pnpm build` | Собрать API, бота и интерфейс |
| `pnpm start` | Запустить собранный API; интерфейс размещается отдельно |

Интеграционным тестам нужен `DATABASE_URL` и пользователь PostgreSQL с правом `CREATEDB`. Они создают временные базы и удаляют только их. GitHub Actions выполняет проверки на отдельной PostgreSQL 16.

## Структура репозитория

```text
apps/
  web/                 Mini App: страницы, API-клиент, MAX Bridge
  api/                 HTTP API, импорт, схема БД и SQL-миграции
  bot/                 Команды MAX и отправка напоминаний
packages/
  contracts/           Общие Zod-схемы и типы
  ui/                  Компоненты интерфейса и стили
data/                 Исходные данные и справочники
  catalog/             Основной CSV каталога
  reference/           Уровни, этапы, вузы и льготы
  faq/                 Вопросы и ответы с источниками
  assistant/           Сайты для поиска ассистента
docs/                  Документация по запуску и устройству проекта
scripts/               Локальная разработка и обработка ресурсов
tests/                 Серверные модульные и интеграционные тесты
apps/web/test/         Тесты клиентской логики
deploy/                Конфигурация HTTPS-прокси
```

Точка входа интерфейса — `apps/web/index.html`. Публикация приложения описана в [инструкции для Docker](docs/DEPLOYMENT.md).

## Данные и ограничения

Основной набор — `data/catalog/olimpiady.csv` (640 записей, выгрузка от 24.09.2026, разделитель `;`). Справочники дополняют его этапами, уровнями и льготами. После импорта приложение читает PostgreSQL. Повторный импорт обновляет каталог и сохраняет пользовательские планы.

Расписание и правила приёма могут меняться: у данных сохраняются источники. Часть дат без года рассчитывается по сезону 2026/27 и помечается как оценочная; это отличается от отдельно проверенных дат. Перед участием нужно сверять сроки и льготы с организатором или вузом. Ассистент зависит от внешнего API; автоматического обновления всего каталога нет.
